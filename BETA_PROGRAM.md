# Super Saber: Closed Beta Program

## Overview
Welcome to the Super Saber 2.0.0 Closed Beta! This program is designed to gather critical feedback from our dedicated community before the public launch. As we have just integrated all core Phase 8 features (115-point scoring, new modifiers, Arcs/Chains), we need your help to stress-test the application across different hardware setups.

## Program Goals
1.  **Balancing & Mechanics Validation**: Ensure the newly implemented 115-point scoring system and advanced modifiers (like Pro Mode and Small Notes) feel accurate and fair compared to legacy rhythm game standards.
2.  **Cross-Modal Testing**: Verify the stability and synchronization between Full VR Mode, the 2D "Corner of my Desk" mode, and the MediaPipe Optical Hand Tracking mode.
3.  **Multiplayer Load Testing**: Push the limits of the WebSocket multiplayer implementation with up to 5 concurrent users per lobby.
4.  **Twitch Integration Verification**: Ensure that chat commands (`!spawn`, `!speedup`, `!hype`) map flawlessly to the new UI modifiers.

## How to Participate
*   **Access**: This beta is invite-only. If you have received a Beta Key, follow the deployment instructions provided to connect to the staging server.
*   **Communication**: Join our dedicated `#super-saber-beta` Discord channel. This is the primary hub for real-time discussion, bug reporting, and updates.

## Feedback Mechanisms
We ask all beta testers to utilize the following channels to report their findings:
1.  **Bug Reports**:
    *   If you encounter a bug, please use the GitHub Issues tracker.
    *   Prefix your issue title with `[BETA]`.
    *   Include your hardware setup (VR Headset model, OS, Browser version) and detailed steps to reproduce the issue.
2.  **Gameplay & Balance Feedback**:
    *   Submit your thoughts on the feel, latency, and balancing of the new mechanics via the [Beta Feedback Google Form] (Link TBD).
3.  **Automated Crash Logs**:
    *   The beta build contains basic telemetry to capture fatal A-Frame rendering crashes. No personal data is collected, but these logs are vital for our CI/CD debugging pipeline.

## Terms of Participation
*   **Confidentiality**: While we encourage discussion within the Discord, please refrain from publicly streaming or sharing footage of the beta build without explicit permission.
*   **Updates**: Expect frequent, sometimes daily, updates pushed through the CI/CD pipeline as we address issues.

Thank you for helping us polish Super Saber into the ultimate web-based rhythm experience!
